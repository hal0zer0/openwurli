# OpenWurli

An *obsessively* physically-modeled Wurlitzer 200A electric piano plugin for CLAP and VST3 hosts. NOT IN ANY WAY OFFICIAL OR AFFILIATED WITH ANYONE.

[![OpenWurli Demo](https://img.youtube.com/vi/2ELaBTO087I/maxresdefault.jpg)](https://youtu.be/2ELaBTO087I)

### Also in Retromulator

[DiscoDSP](https://www.discodsp.com/retromulator/) ported OpenWurli's engine to C++ as the Wurlitzer 200A core of **[Retromulator](https://www.discodsp.com/retromulator/)**, their open-source (GPL-3.0) emulation plugin. It has carried OpenWurli since March 2026 and now runs the 0.9 core. If you need AU or AAX (Logic, Pro Tools), or a standalone app, that's the way to play it. It's an independent port, so report Retromulator issues to DiscoDSP, not here.

## What Is This?

OpenWurli models the complete analog signal chain of a Wurlitzer 200A electric piano from first principles — no samples, no impulse responses, no curve-fitted approximations. Every stage is derived from the actual circuit schematic and validated against SPICE simulations. Which, by the way, was REALLY REALLY HARD. 

That's probably why there are so few decent Wurlitzer style plugins out there. We learned (the hard way, after several false starts) that you cannot come close to approximating the sound of a Wurli without modeling *EVERYTHING* that makes it sound the way it does. We drew from the real 200A schematic diagram to model every resistor, every diode, even the little 4x8 ceramic cone speakers. 

As far as we can tell, this is both the most accurate and best sounding open source Wurli EP plugin in existence. Though there's still room for improvement. 

The signal chain:

1. **Modal reed oscillator** — 7-mode synthesis with per-note frequency ratios, decay rates, and inharmonicity from Euler-Bernoulli beam theory
2. **Electrostatic pickup** — the reed swings into a charged comb; a field-solved capacitance-vs-overlap law (the primary harmonic source) with RC high-pass filter
3. **Hammer model** — Gaussian dwell filter, register-dependent onset ramp, impact noise burst
4. **Preamp** — hand-derived 9-node Modified Nodal Analysis solver of the 200A's two-stage direct-coupled NPN amplifier, on the verified schematic topology. A 12-node solver generated by [melange](https://github.com/hal0zer0/melange) from the same SPICE netlist is available as an opt-in build (`--features melange-preamp`)
5. **Twin-T tremolo oscillator** — melange-generated circuit models the real oscillator waveform; LDR feedback modulation inside the preamp loop (timbral, not just volume)
6. **Power amplifier** — closed-loop negative feedback NR solver with Gaussian crossover distortion and tanh soft-clip rail saturation (a melange-generated 7-transistor solver is available as an opt-in build)
7. **Speaker cabinet** — HPF/LPF with Hammerstein polynomial nonlinearity, tanh excursion limiting, and thermal voice coil compression

## Features

- Physically accurate sound derived from component-level circuit analysis; the tremolo oscillator (and the opt-in preamp and power-amp solvers) are generated by [melange](https://github.com/hal0zer0/melange) from SPICE netlists
- Full 64-voice polyphony (matches real 200A's 64 keys) with voice stealing and crossfade
- 2x oversampled preamp processing (bypassed at >= 88.2 kHz host rates)
- Tremolo that modulates timbre (not just amplitude), matching the real 200A topology
- Per-note MLP corrections trained on real Wurlitzer recordings (experimental)
- Per-note variation in tuning and amplitude (no two notes sound identical)
- Per-mode frequency jitter to break digital coherence
- CLAP and VST3 plugin formats

## Install

Download the latest release from the [Releases](https://github.com/hal0zer0/openwurli/releases) page, then copy the plugin to your host's search path:

| Format | Linux | macOS | Windows |
|--------|-------|-------|---------|
| CLAP | `~/.clap/` | `~/Library/Audio/Plug-Ins/CLAP/` | `%LOCALAPPDATA%\Programs\Common\CLAP\` |
| VST3 | `~/.vst3/` | `~/Library/Audio/Plug-Ins/VST3/` | `%COMMONPROGRAMFILES%\VST3\` |

## Build from Source

Requires [Rust](https://rustup.rs/) (stable toolchain, MSRV 1.85).

```bash
# Clone
git clone https://github.com/hal0zer0/openwurli.git
cd openwurli

# Build and bundle the plugin (release mode)
cargo xtask bundle openwurli --release

# Output: target/bundled/openwurli.clap and target/bundled/openwurli.vst3
```

### Linux Dependencies

```bash
# Debian/Ubuntu
sudo apt install libasound2-dev

# Fedora
sudo dnf install alsa-lib-devel
```

### Run Tests

```bash
cargo test --workspace
```

## Parameters

| Parameter | Range | Default | Description |
|-----------|-------|---------|-------------|
| Volume | 0-100% | 80% | The volume pot between preamp and power amp (audio taper). Like the real amp, full volume with big fortissimo chords can drive it into clipping |
| Tremolo Depth | 0-100% | 50% | Modulation depth (0 = off). Rate fixed at ~5.6 Hz by Twin-T oscillator. |
| Speaker Character | 0-100% | 0% | 0% = flat bypass, 100% = authentic cabinet response |
| MLP Corrections | off/on | off | Per-note corrections trained on real Wurlitzer recordings |
| Authentic Noise | off/on | off | Thermal hiss from every preamp resistor |
| Noise Level | 0-30× | 1× | Noise multiplier; 1× is the physical level |

The plugin's output level is fixed to sit where typical instruments do: playing at the defaults peaks around −6 to −10 dBFS. There is no over-protection, as on the real amplifier, so slamming full volume can go past 0 dBFS; use your DAW's gain to taste.
